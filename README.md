# 🎬 国漫 · 日漫 时间表

一个**零依赖、可安装(PWA)**的追番小工具:按星期或按类型浏览正在连载的日本动画与中国动画,含封面、评分、更新话数/时间、机翻中文简介,可收藏追番并导出/导入(网页版与软件版数据互通),一键跳转国内外站点核对详情。

**纯前端 · 免登录 · 可安装到手机/电脑 · 支持离线外壳 · 自动深浅色 · 可被搜索引擎收录**

</div>

---

## ✨ 功能

- 📅 **星期表 / 类型分类** 两种视图:类型分类视图先分「日漫 / 国漫」,再按 战斗/冒险/奇幻/科幻/剧情/搞笑/日常/恋爱/悬疑… 等类型归类
- 🇯🇵/🇨🇳 一键筛选 **全部 / 日漫 / 国漫**,支持片名即时搜索(中/日/英)
- 🖼️ 封面 + 评分 + 类型 + 制作公司 + 更新话数与预计时间(本地时区)
- 🇨🇳 **简介自动中文化**:展开简介时调用免费翻译接口,机翻缓存、标注「中文(机翻)」
- ⭐ **追番收藏**:点卡片 ☆ 收藏,本地保存;「我的收藏」视图离线也能看
- 💾 **数据互通**:收藏可**导出为 JSON 文件 / 从文件导入**,网页版与软件版/另一台设备之间搬运
- 📱 **PWA 可安装**:手机「添加到主屏幕」/ 电脑浏览器「安装」后像 App 一样全屏运行,支持离线打开外壳
- 🌐 每部番剧直达 **原站 / 班固米 / 哔哩哔哩 / MyAnimeList / AniList** 搜索
- ⚡ **双数据源自动回退**:优先哔哩哔哩番剧时间线(国内中文数据),失败自动切换 AniList(国际数据)
- 🎨 跟随系统深浅色主题;数据可随时手动刷新

## 🚀 快速开始

### 方式一:直接使用

网页已部署在 GitHub Pages 后,打开站点地址即可;或将 `index.html` 下载到本地,**双击用浏览器打开**也能用(需能访问数据源网络;离线外壳与「安装」需部署在 HTTPS 站点)。

### 方式二:部署到 GitHub Pages(PWA 生效)

1. Fork / 上传整个仓库(含 `index.html`、`manifest.webmanifest`、`sw.js`、`icons/`)到你的 GitHub;
2. 仓库 **Settings → Pages**,Source 选 `main` 分支、根目录(`/(root)`);
3. 保存后等待 1~2 分钟,通过 `https://<你的用户名>.github.io/anime-schedule/` 访问;
4. **手机安装**:用手机浏览器打开网址 → 菜单「添加到主屏幕 / 安装应用」;
   **电脑安装**:Chrome/Edge 地址栏右侧「安装」图标 → 安装。

### 方式三:部署到国内(可选)

国内访问优先推荐 **Gitee Pages**(需实名):把整个仓库传到公开仓库 → 仓库「服务 → Gitee Pages」→ 使用默认域名启动即可,免备案(PWA 在部分国内静态托管下可能受限,功能仍可用)。
