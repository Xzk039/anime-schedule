追番时间表 · 桌面版(Windows .exe)打包指南
==========================================

本文件夹 = 一套 Electron 桌面工程,目的:把现有网页包成可双击运行的 .exe 软件。
已包含:index.html(网页)、icons/(图标)、main.js、package.json。

⚠️ 重要前提:
  1) 本机需要能访问外网(AniList 数据在海外),打包和运行都依赖。
  2) "自己电脑打包出的 .exe" 未签名,分享给别人的 Windows 会提示"未知发布者",
     这是正常现象,点"仍要运行"即可;想彻底消除需花钱买代码签名证书(不推荐学生做)。

═══════════════════════════════════════
第一步:安装 Node.js(只需一次)
═══════════════════════════════════════
1. 下载 Node.js LTS 版:https://nodejs.org 点绿色 LTS 大按钮下载。
2. 双击安装,一路 Next(默认选 LiveScript 即可)。
3. 验证:按 Win+R 输入 cmd 回车,输入  node -v  回车,能看到 v20.x 之类即成功。

═══════════════════════════════════════
第二步:进入本文件夹(可选,个人习惯)
═══════════════════════════════════════
在资源管理器进入 C:\Users\xingq\Desktop\anime-schedule-app
在地址栏输入 cmd 回车,会打开命令行并定位到这里。

═══════════════════════════════════════
第三步:安装依赖 + 启动预览
═══════════════════════════════════════
在命令行输入:
  npm install
  (首次会下载 Electron,约 100MB,国内慢可开 Clash 加速)

安装完先预览:
  npm run start
  —— 会弹出软件窗口,此时是开发模式,功能与网页一致。
  看到窗口正常、数据能加载,再关掉窗口。

═══════════════════════════════════════
第四步:打包成 .exe 安装包
═══════════════════════════════════════
在命令行输入:
  npm run build

打包完成(需几分钟)后,在文件夹里会多出 dist\ 目录,
里面有 "追番时间表 Setup 1.0.0.exe" —— 这就是可发给别人安装的软件包。

═══════════════════════════════════════
常见问题
═══════════════════════════════════════
- npm install 卡住/报错:
    → 开 Clash 再试;或设置国内镜像:
      npm config set registry https://registry.npmmirror.com
- npm run build 报 "electron-builder 不是命令":
    → 重新 npm install 一次。
- 打包出来的 exe 别人双击提示"Windows 已保护你的电脑":
    → 更多信息 → 仍要运行(未签名软件的正常提示)。
- 打包很慢/失败(Squirrel / 下载 winCodeSign 卡住):
    → 开代理;或先 npm run start 确认能跑,打包失败不致命——能用就行。
═══════════════════════════════════════
数据互通:桌面版收藏保存在本机;要与网页/安卓互通,用网页里的
「导出收藏 / 导入收藏」JSON 文件搬运。界面与数据源和网页完全相同。
